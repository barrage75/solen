Vous venez de scanner un QR code piégé

Dans une vraie attaque, ce QR code ouvrirait sur votre téléphone une fausse page de paiement. La carte bancaire saisie partirait directement chez le fraudeur.

Le piège est efficace parce que le lien est caché dans une image : les filtres de la messagerie ne le voient pas, et le téléphone personnel échappe aux protections de l'entreprise.

Aucune donnée n'est collectée sur cette page : c'est une démonstration de Solen, avec des données fictives.
